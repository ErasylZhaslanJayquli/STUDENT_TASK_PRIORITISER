## Декларация использования ИИ

| Поле | Содержание |
|---|---|
| Инструмент и версия | Claude (Anthropic), веб-платформа claude.ai, Sonnet 5.5 |
| Цель | Подготовка кода обучения и оценки модели; подключение модели к `app.py` (поле `importance`, `task_manager.py`, сохранение CSV); unit-тесты; черновики README, отчёта и слайдов |
| Генерация датасета | Участник команды Бағлан Исмаилов самостоятельно подготовил синтетический датасет с помощью генеративного искусственного интеллекта. ИИ использовался для создания 100 примеров учебных заданий, включая их характеристики и метки приоритета (High, Medium, Low). Полученный результат был сохранён в CSV-файл и использован для обучения и тестирования модели машинного обучения. Датасет создавался непосредственно для учебного проекта и не содержит реальных персональных данных. |
| Что взято / изменено | С помощью Claude были подготовлены ML-модуль `ml_model.py`, модуль управления заданиями `task_manager.py`, изменения интерфейса `app.py`, автоматические тесты и черновики документации. Полученные материалы были объединены в проект Student Task Prioritizer. ML-модель обучена на синтетическом датасете и интегрирована с интерфейсом Streamlit. |
| Проверка результата | Подготовлены 27 автоматических тестов для проверки ML-модели, обработки данных и управления заданиями. По результатам проверки команды все 27 тестов пройдены успешно. Проверены разделение данных на обучающую и тестовую выборки, вычисление метрик Accuracy и F1-score, формирование матрицы ошибок и три примера предсказаний. Дополнительно проверена структура приложения Streamlit, состоящего из семи страниц. |
| Ограничения ИИ-вывода | Датасет состоит из 100 синтетических примеров, созданных с применением генеративного ИИ. Точные правила присвоения меток priority не задокументированы. Оценка accuracy 0,70 основана только на 20 тестовых заданиях и не подтверждает аналогичное качество на реальных данных студентов. |
